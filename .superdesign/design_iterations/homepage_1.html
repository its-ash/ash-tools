Questions, answered.

Do you store any of my files?

No. Every tool processes data locally in your browser using WebAssembly or native Web APIs. Files never touch a server.

Do I need to create an account?

No sign-up, ever. Open a tool and start using it immediately.

Does it work without an internet connection?

Once a tool's page has loaded, most features keep working offline since there's no server round trip involved.

Is Ash Tools free?

Yes, every tool is free to use with no usage limits or hidden tiers.
